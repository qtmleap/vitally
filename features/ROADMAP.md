# Feature Roadmap

## Priority: High

### バーコードスキャン
- カメラで JAN コードを読み取り、食品情報を自動入力
- Open Food Facts API (無料、APIキー不要) で栄養素を取得
- ライブラリ: html5-qrcode or zxing-js (全ブラウザ対応)
- 食品追加ダイアログにスキャンボタンを追加

### よく食べるもの
- 登録頻度の高い食品をリスト表示
- ワンタップで食事に追加
- 朝食・昼食など時間帯ごとのサジェスト

### 体重記録 + グラフ
- 毎日の体重を記録
- 折れ線グラフで推移を表示 (recharts or chart.js)
- BMI 自動計算
- DB: Weight テーブル追加 (date, weight_kg)

## Priority: Medium

### 週間/月間レポート
- カロリー・PFC の日別推移グラフ
- 週平均・月平均の集計
- 目標達成率の表示
- AI による期間サマリーコメント

### 写真記録
- 食事の写真を Cloudflare R2 に保存
- Meal レコードに photo_url を追加
- 将来的に Workers AI で食品自動推定

### 水分記録
- 1日の水分摂取量をトラッキング
- ワンタップで 200ml / 500ml 追加
- 目標量 (2L) に対する進捗表示

## Priority: Low

### PWA 対応
- Service Worker でオフラインキャッシュ
- manifest.json でホーム画面追加
- プッシュ通知 (記録リマインダー)

### 食事プラン
- 1日の食事プランをテンプレートとして保存
- テンプレートからワンタップで記録

### ソーシャル機能
- 記録の共有 (OGP 画像生成)
- 友人との目標チャレンジ

### データエクスポート
- CSV / JSON でデータエクスポート
- 月次レポートの PDF 出力
